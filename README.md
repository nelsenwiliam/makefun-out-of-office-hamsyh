Entry for the [make.fun bounty "Funniest One-Line Out-of-Office Reply"](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) ($2).

`main.py` (pure Python standard library, no third-party packages) writes a
single out-of-office auto-reply line to `/output/entry.txt`:

> I'm out of office. If it's urgent, it isn't — I checked before I left.

The line inverts the classic "if it's urgent, contact..." trope: the sender
already checked before leaving, so nothing is urgent. It reads like a real
away message a person would gladly switch on, lands on the first read, and
stays clear of the usual beach / inbox / limited-email clichés.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
